# 脉络三：候选分块从哪里来

> 状态：候选来源讨论，尚未固定生成器。返回[Shape 分块总览](../../../lego_shape_decomposition_design.md)。

## 要回答的问题

一次只尝试把当前 Shape 分成两个子 Shape，但需要先产生一组几何上有解释力的候选。候选边界必须在目标 LEGO 尺度仍有意义；“有明显切割信号”不等于“切了就更好”。

上游[几何语言拟合](./02-pattern-language.md)说明父 Shape 哪些区域无法用单一规律解释；细腰、凹陷和分叉则补充几何结构线索。本环节只缩小“在哪里尝试切”的搜索范围。每个候选进入[Split / Build 决策](./04-split-decision.md)后，仍须与不切的父 Shape 比较。

## 候选信号

| 信号 | 思考与理论支撑 | 主要误判风险 |
|---|---|---|
| 细腰与厚度局部极小值 | Skeleton 半径沿路径先减后增，可能表示两个粗区域间的自然连接处 | 装饰性凹槽、目标尺度下过细的噪声 |
| 凹陷 | 凸分解思想可提示一个区域包含多块空间结构 | 凸性不是 LEGO 可拼搭性的充分条件 |
| 曲率或法向突变 | 表面变化可能对应造型边界 | 网格采样、法向噪声或材质边界造成假信号 |
| Skeleton 分叉 | 分叉点提示多个空间方向，如躯干与肢体 | Blob、薄板的骨架不稳定，分叉处切割可能损失连接 |
| Pattern 残差 | 单一规律无法解释的局部区域可提示分块位置 | 拟合模型本身不足时会产生虚假残差 |

区域生长等方法可以作为后续补充，但第一版不应同时堆叠大量 heuristic。

## 借鉴算法时的边界

- **BSP：** 借鉴二分并递归形成树，不预设固定空间切面。
- **BVH / OBB：** 借鉴层次表示和紧致性指标，不能把 Box 填充率作为硬停止规则。
- **Approximate Convex Decomposition：** 借鉴凹陷所提供的自然边界，不能把每个凸块直接当 LEGO 单元。
- **Octree / Adaptive Mesh Refinement：** 借鉴简单处保持粗粒度、只有误差改善才细分的思想，而非从全局体素树开始。
- **Medial Axis / Curve Skeleton：** 借鉴中心路径、厚度和分叉信息，必须允许其对某些 Shape 失效。

## 候选的最低信息

每个候选至少应保留父/子 Shape 的几何范围、切割边界、来源信号及目标尺度下的有效性。评估时重新为两个子 Shape 选轴和拟合 Pattern，而不是沿用父 Shape 的主轴；否则“切后更简单”无法公平比较。

切割是否破坏关键连接、增加局部 Build 与最终合并的难度，属于评估阶段的成本问题，见[Split 决策](./04-split-decision.md)。

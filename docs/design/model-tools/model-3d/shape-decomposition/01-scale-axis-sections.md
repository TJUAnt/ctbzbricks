# 脉络一：目标尺度、主轴与截面

> 状态：几何分析假设，尚无实验验证。返回[Shape 分块总览](../../../lego_shape_decomposition_design.md)。

## 要回答的问题

在不先把整个模型离散成 LEGO 网格的前提下，如何得到能描述局部 Shape 的连续几何信号？分析必须基于用户要求的目标物理尺寸；原 Mesh 中缩放后低于 LEGO 可表达分辨率的细节，不应主导切分。

## 为什么会走到“主轴”

上游的 Split / Build 问题要求判断当前 Shape 是否具有**单一、稳定的变化规律**。直接看三维 Mesh 很难量化“稳定”：同一表面可从许多方向观察，Box 填充率又只给出一个总体数值。若把 Shape 沿一条路径切成有序截面，就能检查轮廓、大小和中心随位置是否保持稳定、单调变化或平滑转向。主轴的作用是为这些截面提供顺序与局部方向，不是预先指定 LEGO 零件的拼装方向。

这也解释了为什么要同时保留多个轴候选：选择不同路径，同一个弯曲 Shape 可能呈现完全不同的截面规律。轴与 Pattern 应作为一组共同评价；若所有候选都无法稳定组织截面，应记录“无可靠单轴”，交给后续候选分块或其他表示研究，而不是强制拟合。下一步如何解释这些序列见[几何语言专题](./02-pattern-language.md)。

## 思考路径

1. **等比缩放并过滤无关细节。** 保留目标尺度下仍能表达的细腰、分叉、凹陷和表面变化。这里的过滤不是全局体素化，也不预先决定零件摆放。
2. **生成多个候选主轴。** PCA、OBB 的主方向适合近似直线或板状区域；Curve Skeleton / Medial Axis 的路径适合弯曲肢体、尾巴等形状。它们都是候选来源，不是对任意 Shape 都有效的答案。
3. **沿每个轴取得截面序列。** 对候选轴 `A(t)`，采样 `Q_i = S ∩ Plane(A(t_i))`，记录面积、宽高、截面中心、朝向与轮廓，观察这些属性如何随 `t` 变化。
4. **允许没有可靠主轴。** Blob、多分叉或复杂薄壳可能无法由一条路径描述。需要记录轴的可信度及失败原因，不得强迫选择 PCA 最长轴。

## 理论依据与局限

- 截面序列把三维形态转成沿一维参数变化的多组函数，如 `Area(t)`、`Center(t)`、`Contour(t)`；稳定、单调、单峰或平滑转向更容易在该表示中识别。
- PCA 只总结全局方差，弯曲路径的全局主轴可能穿出 Shape。Skeleton 能提供内部路径、局部厚度和分叉，但扁平或近球状区域可能有不稳定的 Skeleton。
- 拼接主轴应是**让截面变化最易用简洁几何规律解释**的方向或路径，而非几何上最长的方向。形式上可把 `argmin_A Complexity(CrossSection(S, A))` 当作研究目标；`Complexity` 尚无定稿。
- 面积、宽高相同仍可能对应完全不同的轮廓，因此截面比较至少需要轮廓相似性。对弯曲轴还要明确局部截面平面如何随切向连续转动，避免采样方式本身制造变化。

## 待验证与产出

首版只需要 PCA、OBB 与截面采样基线，再与 Skeleton 路径比较。记录每个候选轴的截面序列、轴可信度与失败样例。采样间距、尺度过滤规则和可信度公式都应由目标尺度下的数据实验决定，不在讨论稿中固定阈值。

# 脉络二：局部 Shape 的几何语言

> 状态：四种 Pattern 是待验证的最小假设。返回[Shape 分块总览](../../../lego_shape_decomposition_design.md)。

## 要回答的问题

一个局部 Shape 何时可以视为单一、稳定的造型规律，并交给 LEGO Build？Box 填充率和凸性不能直接回答：长斜面或弯曲尾巴的包围盒填充率可能低，却有简单规律；接近实心 Box 的区域也可能有复杂表面。

## 与前后环节的关系

“用规律解释 Shape”是从固定停止条件失败后提出的概念；[主轴与截面专题](./01-scale-axis-sections.md)提供计算它所需的有序观测。Pattern 拟合必须在各个候选轴上分别进行：先选轴再强行套规律，可能把弯曲尾巴误判为复杂 Shape。拟合结果包括最佳规律、残差和轴可信度；残差较大的位置可以提示[候选切分](./03-split-candidates.md)，但不能单靠残差决定 Split，因为缺少的可能是第五种规律。

## 四种待验证的规律

| Pattern | 截面序列中的主要现象 | 可能覆盖的局部造型 |
|---|---|---|
| Constant | 尺度、轮廓和朝向大体稳定 | Box、板、杆、近似挤出体 |
| Taper | 归一化轮廓相似，尺度规律地单调增减 | 楔形、渐细肢体、车头 |
| Bend | 截面相对稳定，中心路径连续转向 | 尾巴、角、弯曲管状结构 |
| Bulge | 截面尺度先增大后减小，近似单峰 | 头部、躯干、舱体 |

这不是已证明完备的形状分类。轮拱、L 型、薄翼、薄壳、鞍形或连接区可能需要不同的描述，不能为了维护四类的覆盖率而强行归类。

## 拟合思路与限制

- **Constant：** 比较截面尺寸、朝向和轮廓；`1 - IoU(Q_i, Q_ref)` 是轮廓误差的一个候选，面积相近不能替代轮廓比较。
- **Taper：** 尺度归一化后比较轮廓，再检查尺度变化的单调性与规律性。线性函数只是基线，不应预设所有自然收缩都是线性的。
- **Bend：** 检查截面稳定性、中心路径的曲率变化与路径复杂度。任意 spline 都能贴近采样点，故必须惩罚过度复杂的路径。
- **Bulge：** 检查尺度函数是否近似单峰；两个明显峰及中间谷可能提示分块，但局部噪声不能制造虚假的多个峰。

可暂记 `PatternError(S) = min_{A,L} Error(S, Model(A,L))`，其中 `A` 是候选轴，`L` 是 Pattern。这个表达只说明研究方向；误差归一化、不同尺度比较、各属性权重都未定稿。

## 不能混同的两种难度

`C_pattern` 表示几何规律是否简单，`C_discretization` 表示目标 LEGO 尺度能否表达它。一个小尺寸球体可能有很低的 Bulge 拟合误差，却因仅有少数 stud 的分辨率而难以逼近。高离散难度本身也不意味着继续切分，因为两个更小的半球通常更难表达。

## 验证问题

对人工标注为“无需继续分”的局部 Shape，检查四种 Pattern 的覆盖率和拟合残差。覆盖不足时先修订几何语言，再优化拟合公式；之后再与真实 LEGO 求解误差、零件数和成功率对照。
